# ORBITALIS

**A 2D orbital mechanics sandbox built with Python.**

ORBITALIS is a personal software development project focused on simulating and visualizing gravitational interactions between celestial bodies.

## Current Features

- Newtonian gravitational interaction between multiple bodies.
- Position and velocity-based celestial body representation.
- Numerical integration using the semi-implicit Euler method.
- Basic 2D visualization using Tkinter.
- Real-time simulation with adjustable simulation parameters in the code.

## Technology Stack

- Python 3.12+
- Tkinter
- Git and GitHub

## Running the Project

Activate the virtual environment and run:

```bash
PYTHONPATH=src python -m orbitalis.main
```

Early development – initial simulation engine and visualization implemented.
